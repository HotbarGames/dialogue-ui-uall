# Promo videos: what to post where

Two videos, rendered from the private video project:

- **The short** (`short-ua.mp4` here, 19 s, 1080x1920): the main one, for TikTok, YouTube Shorts and Instagram Reels,
  and the one the READMEs link. Cover: `short-cover.png`.
- **The explainer** (`promo-ua.mp4` here, 53 s, 16:9): for a normal YouTube video. There is also a version with the
  UALL voice line, published only after the UALL team says yes (their audio).

## The short (TikTok / Shorts / Reels)

**When:** only after the CurseForge project is approved and findable by name (the video says «шукай на CurseForge»).
Best moment: the evening before WoW Forever opens (Nov 4, 18:00–21:00 Kyiv; the servers open Nov 5, 01:00 Kyiv),
or right after the approval if that comes later.

**Caption** (the same on all three):

```
Dialogue UI тепер українською 🇺🇦 Шукай на CurseForge: «Dialogue UI - UALL». І грай рідною!
#wow #worldofwarcraft #wowforever #wowукраїнською #українською #українськийтікток #геймінг #аддони
```

**Pinned first comment:**

```
Як встановити: у застосунку CurseForge знайдіть «Dialogue UI - UALL» → Install. Dialogue UI та UALL Forever він поставить сам. Українська озвучка — окремий аддон від команди UALL, за бажанням. Посилання: curseforge.com/wow/addons/dialogue-ui-uall
```

**When posting:**

- Cover: upload `short-cover.png`, or pick the frame where the bar crosses the middle of the window (about 5.3 s).
- TikTok: switch on «Вміст, створений ШІ» (the narrator is an AI voice).
- Optional: add a trending sound in the app at 5–10 % under the original sound (keep the original at 100 %).
- YouTube Shorts title: «Dialogue UI тепер українською 🇺🇦 #wowforever #worldofwarcraft». Description: the caption
  above plus the credit lines from the explainer description below.
- In the first hour, answer comments («де скачати?»; «а для Retail?»: no, only WoW Forever). That is when the feed
  decides whether to show the video to more people.

Narration of the short: AI voice (ElevenLabs, «Leonid Polishchuk»). It never says "free" (everything on
CurseForge is), on purpose. The beat and sound effects are made in code: no
licensed music.
